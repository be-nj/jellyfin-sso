With more than one enabled provider, /sso/oidc/start asks the user which one to use.

Sessions

On its own this changes nothing visible: it decides what /sso/oidc/logout does. Jellyfin's own logout button can only be wired to it with a snippet in the web client — see docs/login-and-logout.md.
Writes one button per enabled provider into Jellyfin's login disclaimer. Turn it off if you place your own button with the JavaScript Injector and do not want a second one below the form.
Fetches the logo your provider shows on its own login page, so a rebranded Authentik looks like itself here too. The server fetches and caches it; the login page never reaches out to the provider. Off means the plugin's stock mark.
Adds a small script to Jellyfin's web page as it is served, so the button sits with Sign In instead of below the form. Nothing is written to disk, and turning it off removes it again. Leave the setting above on as well only if you want a button in both places.
Signed-in users can link an SSO identity themselves at /sso/link. An identity already linked to another account is refused.
Applied declaratively on every login — Jellyfin user UI changes are overwritten.

Safety

Without this, a renamed or mistyped admin group demotes your administrators on their next login. The last remaining administrator is always kept, either way.
